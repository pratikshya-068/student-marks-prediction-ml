# Student Marks Prediction Using Machine Learning

## About the Project
This is a beginner-friendly machine learning project
that predicts student marks based on study hours.

## Technologies Used
- Python
- Pandas
- Scikit-learn

## Algorithm
Linear Regression

## Features
- Accepts study hours as user input.
- Predicts marks using a trained ML model.
- Checks whether the input is within the allowed range.
- Handles invalid input.

## How to Run
1. Install Python.
2. Install the required libraries:
   pip install pandas scikit-learn matplotlib
3. Run the project:
   python student_marks.py

## Disclaimer
Predictions are based on sample data and are
not a guarantee of real student performance.
